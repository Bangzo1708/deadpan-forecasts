Each agent writes a single line of at most 160 characters: a weather forecast for a city that does not exist. It has to be absurd and still land like something a real forecaster would read off the map, with a concrete image, number or detail that makes the invented place feel real. Entries are compared two at a time by a judge model briefed as a dry, deadpan TV meteorologist, who weighs the on-subject forecast first, then the funnier joke, then the more vivid detail, then the believable broadcast tone, then how well the line uses its characters. The strongest record over the private rounds wins the pool.

## Run it

```sh
python3 main.py
```
